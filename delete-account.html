Account & Data Deletion

अपना account और personal data हटाने का अनुरोध

PanchayatX account और associated personal data deletion request की प्रक्रिया।

Deletion request कैसे करें

PanchayatX account holder account/support channel के माध्यम से Account Deletion request कर सकता है। यदि login संभव नहीं है, Contact page के support route से request भेजें और ownership verification के लिए पर्याप्त account details दें।

क्या delete/anonymise किया जाता है

Identity/ownership verification के बाद account profile information और user-created personal data को delete या anonymise किया जाता है, सिवाय उस data के जिसे security, fraud prevention, payment dispute, accounting या legal obligations के लिए रखना आवश्यक हो।

क्या delete नहीं होता

PanchayatX account deletion government/election authority के electoral-roll records या ऐसे independent source records को delete/alter नहीं करता जिन्हें PanchayatX control नहीं करता।

Processing

Deletion request verification के बाद process की जाती है। यदि किसी lawful purpose के लिए limited records retain करना आवश्यक हो, तो उनका उपयोग उसी purpose तक सीमित रखा जाता है जैसा Privacy Policy में बताया गया है।

App users: Account deletion request के लिए यही web page public request route के रूप में उपलब्ध है।
